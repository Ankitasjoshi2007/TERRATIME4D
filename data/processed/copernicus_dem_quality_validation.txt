2. BASIC RASTER VALIDATION
--------------------------
All 13 TIFF files were successfully opened using Rasterio.

All 13 tiles:
- Have readable elevation values.
- Have valid raster dimensions.
- Use EPSG:4326.
- Have NoData metadata set to None.
- Report MaskFlags.all_valid.
- Have valid raster-mask pixels.

IMPORTANT:
An all-valid raster mask does not prove that every pixel represents
a genuine land elevation. Additional scientific checks are required.

3. TERRAIN ANALYSIS
-------------------
The current terrain dataset contains the following standardized
metrics for each downloaded tile:

- Minimum elevation
- Maximum elevation
- Average elevation
- Average slope
- Maximum slope
- Relief
- Average roughness
- Terrain class

Terrain classes are TerraTime 4D heuristic categories based on
average slope and average roughness:

- Flat
- Rolling
- Hilly
- Steep
- Rugged

These terrain classes are project-defined analytical categories
and are not official NASA or ESA classifications.

5. ZERO AND NEGATIVE ELEVATION CHECK
------------------------------------
The original detailed zero/negative elevation investigation was
performed for the Hawaii tile.

Hawaii:
Zero pixels: 1,390,742
Negative pixels: 1
Pixels between 0 and 1 metre: 38
Zero elevation percentage: 96.58%

The Hawaii tile contains a strong spatial concentration of
zero-elevation pixels. These pixels should not automatically be
treated as valid land elevation.

6. HAWAII SPATIAL ZERO-VALUE INVESTIGATION
------------------------------------------
Total pixels: 1,440,000
Non-zero pixels: 49,258
Zero pixels: 1,390,742
Non-zero percentage: 3.42%

Non-zero pixel geographic extent:
Latitude: 19.3358 to 19.7308 degrees North
Longitude: 155.0000 to 154.8075 degrees West

A 10 by 10 block analysis revealed that zero elevations are
strongly spatially clustered.

The spatial pattern is consistent with the geography of the
Big Island of Hawaii and surrounding ocean.

This demonstrates why raster validity flags alone are insufficient
for scientific terrain analysis.

7. WORLD COVER CROSS-VALIDATION
-------------------------------
An existing ESA WorldCover land-cover analysis was used for
additional investigation of the Hawaii tile.

Total DEM pixels: 1,440,000
Permanent water pixels (class 80): 449,667
Land-classified pixels: 49,029
Unclassified pixels (class 0): 941,304

All 941,304 unclassified pixels have exactly zero DEM elevation.

WorldCover class 0 represents unclassified or NoData pixels,
not confirmed ocean.

Some class 80 pixels have unexpectedly elevated DEM values.
The maximum observed elevation in class 80 is 135.99 metres.

These disagreements require further independent investigation.

8. SCIENTIFIC LIMITATIONS
-------------------------
- NoData metadata is absent from the examined Copernicus DEM tiles.
- Raster masks alone cannot guarantee genuine land elevation.
- Zero elevation must not automatically be interpreted as NoData.
- Zero elevation must not automatically be interpreted as ocean.
- WorldCover classification is not assumed to be error-free.
- Spatial agreement does not independently prove data correctness.
- High-latitude raster resolution varies geographically.
- The current dataset is a representative sample of downloaded
  Copernicus DEM tiles, not a complete global DEM download.
- Terrain classes are project-defined heuristic categories.

Original DEM and WorldCover values have been preserved.

10. CONCLUSION
--------------
The current TERRATIME 4D Member 1 dataset contains 13 downloaded
Copernicus DEM GLO-30 tiles.

All 13 tiles are available locally and have been processed for
elevation, slope, relief, roughness, and terrain classification.

The quality-control workflow also documents raster validity,
spatial zero-value investigation, and WorldCover cross-validation.

The resulting standardized terrain dataset provides the Earth
terrain foundation for comparing terrestrial environments with
Moon and Mars mission-relevant terrain characteristics.

Further global expansion can be performed later if required,
but the current 13-tile dataset provides a validated sample
for downstream TERRATIME 4D analysis.
